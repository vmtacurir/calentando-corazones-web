# Flyer actual

Guarda en esta carpeta el flyer que debe aparecer en la portada con el nombre exacto:

`flyer-actual.webp`

Cuando haya una nueva actividad:

1. Reemplaza el archivo conservando el mismo nombre.
2. Usa una imagen vertical de proporción 4:5 y un peso menor a 500 KB.
3. Actualiza en `index.html` el día, la hora, el punto de encuentro, los contactos y el texto alternativo.
4. Revisa el resultado en Google Chrome antes de publicarlo.

La configuración de Azure obliga al navegador a comprobar si existe una versión nueva del flyer.
